## CPU/GPU boundary

Visibility is a deterministic AABB bounding-volume experiment, not exact mesh occlusion. The
custom Warp distance kernel has a CPU oracle and is validated in the CUDA test suite when a CUDA
device is present. This host reports `CUDA driver/device is unavailable.`, so the local status is
intentionally PARTIAL unless CUDA validation is available.

Future GPU work should keep immutable bounds resident, batch ray and broad-phase kernels, and
perform filtering/ranking reductions before transferring selected candidates to Python.

## Limitations

- Local audit is CPU-only when no CUDA driver is available.
- Visibility uses deterministic AABB ray tests, not exact triangle-mesh rays.
- Batched rotation and scale are stored but predicate evaluation is not implemented yet.
